## 📈 Key Metrics to Track

Monitor these in **Google Search Console** (https://search.google.com/search-console):

- **Impressions** — How many times you appear in search
- **Clicks** — How many clicked to your site
- **Average position** — Where you rank (lower = better)
- **Click-through rate** — % who click from search results

Update your content based on what's working:
- High impressions but low clicks? → Rewrite title/description
- Good rankings but low clicks? → Improve meta description
- Trending topic getting searches? → Write about it

## ⚠️ Common Mistakes to Avoid

1. **Keyword stuffing** — Don't repeat "PAN card" 50 times. Write naturally (2-3% density).
2. **Thin content** — Blog posts need 1000+ words to rank. Fluff doesn't work.
3. **No internal links** — Link your blog guides back to each other. Help Google crawl.
4. **Ignoring user intent** — Answer "WHY are PAN photos needed?" not just "WHAT are specs."
5. **Sporadic publishing** — 1 guide every month for consistency beats 5 guides then nothing.
6. **No promotion** — Write it, then promote on Reddit/Quora/communities.
