## SEO Checklist Before Publishing

- [ ] **Title:** Includes primary keyword, 50-60 characters
- [ ] **Meta description:** 150-160 characters, includes keyword
- [ ] **H1:** Present, includes primary keyword
- [ ] **H2/H3:** Clear hierarchy, descriptive
- [ ] **Internal links:** 3-5 links to related content
- [ ] **Images:** All have descriptive alt text
- [ ] **Word count:** Minimum 1000 words (1500+ better)
- [ ] **Keyword density:** Primary keyword appears 2-3% of text naturally
- [ ] **CTA:** Clear call-to-action button visible
- [ ] **FAQ:** Covers common user questions
- [ ] **Readability:** Short paragraphs, bullet points, subheadings
- [ ] **Mobile-friendly:** Preview on phone
- [ ] **Proofreading:** No typos or grammatical errors

## Tips for High Rankings

1. **Answer user questions** — Each H2 section should answer a specific question (how?, what?, why?)
2. **Use keyword naturally** — Don't force; read aloud to check if it sounds natural
3. **Depth beats length** — 1000-word deep dive ranks better than 2000-word fluff
4. **Update regularly** — Add new information, refresh dates, keep current
5. **Link like a map** — Use internal links to guide readers (and Google)
6. **Optimize for features** — FAQ for rich snippets, tables for featured snippets
